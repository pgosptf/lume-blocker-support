# Lume Blocker Support

For issues and suggestions about the Firefox extension, [open an issue](https://github.com/pgosptf/lume-blocker-support/issues/new).

Include your Lume and Firefox versions, steps to reproduce, and the expected result. Add screenshots when they help explain the problem.

Issues are public. Do not post backups, browsing history, tokens, or pairing codes.

To delete synchronized data, use **Settings → Cloud Sync → Delete Cloud Data** in the extension. Your local data stays on your device.
